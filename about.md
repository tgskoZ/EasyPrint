# EasyPrint

**Screenshots without leaving the game.** Press <cy>Print Screen</c>, drag out the area you want, and it goes straight to your clipboard. Paste it into Discord, Telegram, Paint, anywhere with <cg>Ctrl+V</c>.

## How to use
1. Press <cy>Print Screen</c>. The game freezes on the current frame (a level gets paused).
2. Hold the <cg>left mouse button</c> and drag a rectangle over the area you want.
3. Release the button. Done, the picture is in your clipboard.

- <cg>Enter</c> or <cg>Space</c>: copy the whole screen.
- <cr>Esc</c> or <cr>right click</c>: cancel.

## Why?
Normally pressing Print Screen in Geometry Dash brings up Windows' own snipping tool. The game loses focus and can **freeze, minimize or crash**, especially in fullscreen. EasyPrint does the selection inside the game instead:

- <cg>No crashes</c>: Windows never sees the key while the game is in front, so nothing pops up.
- <cg>No hassle</c>: select, release, paste.
- <cg>Exact frame</c>: the picture is read straight from the game at your window's resolution, without the cursor or the selection box.

## Settings
- **Select Area**: choose the area after pressing Print Screen (on by default). Turn off to copy the whole screen instantly.
- **Block Windows Print Screen**: stop Windows from handling the key while GD is focused (on by default).
- **Show Notification**: show the "Screenshot copied!" message.
- **Also Save To File**: also save each screenshot as a `.bmp` file in the mod's save folder.
