# EasyPrint

**Screenshots in one key press.** Press <cy>Print Screen</c> and a screenshot of the game goes straight to your clipboard. Paste it into Discord, Telegram, Paint, anywhere with <cg>Ctrl+V</c>.

## Why?
Normally pressing Print Screen in Geometry Dash brings up Windows' own screenshot tools. The game loses focus and can **freeze, minimize or crash**, especially in fullscreen. EasyPrint fixes that:

- <cg>No crashes</c>: while the game is in front, Windows never sees the key, so nothing pops up and the game keeps running.
- <cg>No hassle</c>: no Snipping Tool, no cropping, no saving. Press the key and paste.
- <cg>Exact frame</c>: the picture is read straight from the game at your window's resolution, without the cursor or other windows.
- A small notification tells you it worked.

## Settings
- **Block Windows Print Screen**: stop Windows from handling the key while GD is focused (on by default).
- **Show Notification**: show the "Screenshot copied!" message.
- **Also Save To File**: also save each screenshot as a `.bmp` file in the mod's save folder.
